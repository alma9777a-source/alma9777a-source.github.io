사무용 · 오래된 Windows PC에서
빠르게 쓰기
그래픽 카드가 없는 PC를 위한 ‘빠른 받아쓰기 모델’ 안내

남은 조각은 설교를 PC 안에서 받아씁니다. 영상을 밖으로 보내지 않는 대신, PC 성능에 따라 받아쓰는 시간이 크게 달라집니다. 게임용 그래픽 카드가 있는 PC는 30분 설교를 1분 안에 받아쓰지만, 교회 사무실의 사무용 PC나 노트북은 같은 일을 훨씬 오래 합니다. 이런 PC를 위해 가볍게 줄인 받아쓰기 모델(약 570MB)을 따로 준비했습니다.

이런 PC라면 이 안내를 따라 주세요

🖥️ 교회 사무실의 사무용 PC
💻 노트북 · 몇 년 된 PC
🐢 받아쓰기가 10분 넘게 걸릴 때
🎮 ‘GeForce · Radeon RX’ 같은 그래픽 카드가 없는 PC

잘 모르시겠으면 남은 조각의 설정 › 받아쓰기 모델을 열어 보세요. ‘그래픽 카드가 없어 빠른 모델을 씁니다’라고 나오면 이 PC가 해당합니다.

세 가지 방법 — 위에서부터 해 보세요

가장 쉬움 · 먼저 해 보세요

방법 1 — 앱에서 ‘빠르게’ 고르기

  1. 남은 조각을 켜고 오른쪽 위 설정을 누릅니다.
  2. 받아쓰기 모델에서 빠르게를 누릅니다. (그래픽 카드가 없는 PC는 ‘자동’이어도 빠른 모델을 씁니다.)
  3. ‘내려받기’ 창이 뜨면 기다립니다. 약 570MB를 한 번만 받습니다(인터넷 속도에 따라 몇 분).
  4. 상태가 ‘빠른 모델 · 준비됨’으로 바뀌면 끝입니다. 다음 받아쓰기부터 빨라집니다.
앱 안 내려받기가 멈추거나 끊길 때

방법 2 — 내려받기 도구 실행하기

교회 인터넷이 느리거나 앱 안에서 내려받기가 자꾸 끊길 때 씁니다. 두 번 눌러 실행하면 같은 모델을 앱이 쓰는 폴더에 받아 줍니다. 끊기면 다시 실행해 이어 받습니다.

⬇ 내려받기 도구 받기 (namunjogak-fast-model.bat)
  1. 위 단추로 받은 namunjogak-fast-model.bat 파일을 두 번 누릅니다.
  2. ‘Windows의 PC 보호’ 파란 창이 나오면 추가 정보 → 실행을 누릅니다. (인터넷에서 받은 실행 파일에 처음 한 번 나오는 창입니다.)
  3. 검은 창에 진행 막대가 나오며 내려받습니다. ‘다 받았습니다!’가 나올 때까지 창을 닫지 마세요.
  4. 남은 조각을 껐다가 다시 켜고, 설정 › 받아쓰기 모델 › 빠르게를 고릅니다.

이 도구는 메모장으로 열어 내용을 볼 수 있습니다. 모델 파일 하나를 %APPDATA%\설교쇼츠\모델 폴더에 받는 일만 하고, 다른 설정은 바꾸지 않습니다. Windows 10(1803 이후) · 11에 들어 있는 curl을 씁니다.

인터넷이 안 되는 PC · 방송실 PC

방법 3 — 직접 받아 넣기

방송실 PC처럼 인터넷이 막혀 있으면, 다른 PC에서 받아 USB로 옮겨 넣습니다.

  1. 인터넷이 되는 PC에서 모델 파일을 받습니다 — ggml-large-v3-turbo-q5_0.bin (약 574MB, whisper.cpp 공식 모델).
  2. 남은 조각을 쓸 PC에서 Windows 키 + R을 누르고 %APPDATA%\설교쇼츠를 붙여 넣은 뒤 확인을 누릅니다.
  3. 열린 폴더 안에 모델 폴더가 없으면 새로 만듭니다(오른쪽 클릭 › 새로 만들기 › 폴더 › 이름 ‘모델’).
  4. 받은 파일을 모델 폴더에 그대로 넣습니다. 파일 이름은 바꾸지 마세요.
  5. 남은 조각을 다시 켜고 설정 › 받아쓰기 모델 › 빠르게를 고릅니다. ‘빠른 모델 · 준비됨’이 나오면 됩니다.

남은 조각을 한 번도 켜지 않은 PC에는 설교쇼츠 폴더가 아직 없습니다. 먼저 남은 조각을 한 번 켰다가 끈 뒤 진행해 주세요.

함께 하면 더 빨라지는 것

  • 설교 부분만 받아쓰기 — 첫 화면 ‘시작 설정’에서 받아쓸 부분을 ‘설교 부분만’으로 바꾸면 찬양 · 기도 · 광고를 건너뛰어 그만큼 빨라집니다.
  • 노트북은 전원을 꽂고 — 배터리로 쓰면 Windows가 속도를 낮춥니다.
  • 다른 프로그램은 닫고 — 받아쓰는 동안 방송 프로그램 · 브라우저 탭을 줄이면 도움이 됩니다.
  • 기다리는 동안 다른 일을 — 받아쓰는 동안 ‘남은 시간’이 표시되고, 끝나면 완성본 6개가 저절로 나옵니다.

자주 묻는 질문

빠른 모델은 받아쓰기가 덜 정확한가요?

같은 모델을 가볍게 줄인 판이라 설교 받아쓰기에서는 차이가 거의 없습니다. 드물게 낱말 하나가 다르게 나오면 다듬기 화면에서 자막을 눌러 고치면 됩니다.

그래픽 카드가 있는 PC도 이걸 써야 하나요?

아닙니다. 그래픽 카드가 있는 PC는 ‘자동’으로 두시면 정확한 모델로 빠르게 받아씁니다.

맥도 해당되나요?

아닙니다. 애플 실리콘 맥은 처음부터 빠르게 받아쓰므로 따로 할 일이 없습니다.

그래도 느리거나 잘 안 되면요?

묻고 답하기에 PC 이름(또는 사진)과 걸린 시간을 남겨 주세요. 확인해 답을 드립니다.
