1. 기기 안에만 저장되는 정보

사용자가 넣은 설교 영상, 받아쓴 글, 만든 쇼츠 영상, 교회 이름·로고, 앱 설정은 사용자의 기기 안에만 저장됩니다. 받아쓰기는 기기 안에서 처리하며 영상이나 소리를 외부로 보내지 않습니다. 만든 곳은 이 정보에 접근할 수 없습니다.

사용자가 앱에서 ‘유튜브 연결’을 누르고 구글 로그인으로 허락한 경우에만 아래 권한을 씁니다.

3. Google 사용자 데이터를 보호하는 방법

앱이 다루는 Google 사용자 데이터는 유튜브 연결 토큰(구글이 발급한 접근 권한)과 연결한 채널의 이름 두 가지뿐입니다. 이 데이터는 아래와 같이 보호합니다.

  • 저장 — 기기 안에서만, 암호화하여. 연결 토큰은 사용자 기기의 운영체제가 제공하는 키체인(macOS · iPadOS Keychain)에만 보관합니다. 키체인은 운영체제가 암호화하고 기기 로그인으로 보호하는 저장소입니다. 올릴 때 잠깐 쓰는 단기 토큰은 메모리에만 두고 파일로 남기지 않습니다. 채널 이름은 화면에 보여 주려고 기기 안의 앱 설정에만 둡니다.
  • 만든 곳의 서버에 두지 않습니다. 만든 곳은 Google 사용자 데이터를 받거나 보관하는 서버를 운영하지 않습니다. 따라서 만든 곳과 그 구성원은 이 데이터를 볼 수 없습니다.
  • 전송 — 암호화된 연결로, 구글에만. Google 사용자 데이터는 사용자의 기기와 구글 · 유튜브 서버 사이에서만 오가며, 모든 전송은 HTTPS(TLS)로 암호화됩니다. 다른 회사나 사람에게 보내지 않습니다.
  • 로그인 — 구글의 화면에서. 구글 로그인은 운영체제의 브라우저(아이패드는 시스템 로그인 창)에서 OAuth 2.0과 PKCE 방식으로 이루어집니다. 앱은 사용자의 구글 비밀번호를 받거나 볼 수 없습니다.
  • 최소한의 권한. 앱은 위 표의 두 권한만 요청하며, 그 밖의 Google 데이터에는 접근하지 않습니다.
  • 보관 기간과 삭제. 연결 토큰과 채널 이름은 사용자가 연결을 해제할 때까지만 기기에 남습니다. 연결을 해제하면 즉시 지우고 구글에 권한 취소를 요청합니다(아래 4항).
  • 문제가 생겼을 때. 보안 문제를 발견하시면 아래 문의처로 알려 주세요. 확인하는 대로 고치고 필요한 조치를 안내하겠습니다.

4. 연결 해제와 삭제

앱의 설정 › 유튜브 연결 › 연결 해제를 누르면 기기에 보관된 토큰을 지우고 구글에 권한 취소를 요청합니다. 구글 계정의 보안 설정 페이지(https://myaccount.google.com/permissions)에서도 언제든 권한을 취소할 수 있습니다. 앱을 지우기 전에 연결을 해제해 주세요. 그러면 키체인에 든 연결 토큰까지 남김없이 지워집니다.

5. AI 기능

사용자가 ‘AI 채팅 붙여넣기’나 ‘자동(API)’ 방식을 고른 경우, 받아쓴 설교 글이 사용자가 직접 고른 AI 서비스(Claude·ChatGPT·Gemini)로 전달됩니다. 이는 사용자가 그 서비스에 직접 붙여 넣거나 사용자의 API 키로 보내는 것이며, 해당 서비스의 개인정보처리방침이 적용됩니다. 구글(유튜브) 사용자 데이터는 AI 서비스로 보내지 않습니다.

6. 구입 신청 정보

앱의 등록 화면에서 ‘신청 보내기’를 누르거나 구매 번호로 등록하는 경우에만 아래 정보가 만든 곳의 판매 장부로 전달됩니다. 신청하지 않으면 아무것도 보내지 않습니다.

  • 보관하는 정보 — 신청하신 분이 적은 이름과 메일 주소, 앱이 만든 기기 번호(8자리), 기기 종류(맥 · Windows), 구매 번호, 등록 코드, 신청 · 등록 날짜.
  • 쓰는 곳 — 결제를 확인하고, 그 기기에 맞는 등록 코드를 전하며, 기기를 바꾸었을 때 다시 발급하기 위해서만 씁니다. 광고나 다른 용도로 쓰지 않고 다른 사람에게 넘기지 않습니다.
  • 보관하는 곳 — 만든 곳의 구글 계정에 있는 비공개 구글 스프레드시트(Google Workspace 서비스)입니다. 만든 곳 외에는 볼 수 없습니다. 카드 번호 같은 결제 수단 정보는 받지 않습니다.
  • 보관 기간과 삭제 — 등록 코드를 다시 발급해 드릴 수 있도록 보관하며, 아래 문의처로 요청하시면 지워 드립니다(지운 뒤에는 재발급에 기기 번호를 다시 알려 주셔야 합니다). 관련 법이 보관을 요구하는 거래 기록은 그 기간 동안 보관합니다.
  • 이 정보는 2번의 Google 사용자 데이터(유튜브 연결)와 무관합니다. 유튜브 연결 토큰이나 채널 정보는 판매 장부로 전달되지 않습니다.

Privacy Policy (English)

Effective date: October 7, 2026 · Last updated: October 15, 2026. Nanum Jogak (“we”) provides the Namun Jogak app for macOS and iPadOS. While you use the app, we do not collect or store your videos, transcripts or Google account data on any server. Only if you request a registration code for the Mac or Windows app do we keep the minimal purchase details described under “Purchase requests” below.

Data stored on the device only

Sermon videos, transcripts, rendered videos, church name/logo and settings are stored only on the user’s device. Transcription runs on the device; audio and video are never sent to us.

Google user data (YouTube)

Only when the user chooses “Connect YouTube” and grants consent, the app uses:

  • youtube.upload — to upload the single Shorts video the user selects, with the title, description, tags, privacy status and optional scheduled publish time the user enters, to the user’s own channel.
  • youtube.readonly — only to display the name of the channel the video will be uploaded to.

OAuth tokens are stored only in the device keychain and are never sent to us or any third party; the app communicates directly with Google/YouTube servers. The app does not read or modify the user’s other videos, comments, subscribers or watch history, and does not delete or edit videos. Google user data is not used for advertising, sold, shared, or used to train AI models.

Namun Jogak’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; by using this feature users agree to the YouTube Terms of Service, and the Google Privacy Policy applies.

Data protection — how Google user data is secured

The only Google user data the app handles is the OAuth token issued by Google and the name of the connected channel. We protect it as follows:

  • Storage: on the device only, encrypted. The OAuth refresh token is stored only in the operating system’s Keychain (macOS / iPadOS), which is encrypted by the operating system and protected by the device login. Short-lived access tokens are held in memory only while uploading and are never written to disk. The channel name is kept only in the app’s local settings on the device, to display it.
  • No developer servers. We do not operate any server that receives or stores Google user data, so we and our staff cannot access it.
  • Transmission: encrypted, to Google only. Google user data travels only between the user’s device and Google/YouTube servers, always over HTTPS (TLS). It is not transferred to any other party.
  • Sign-in on Google’s own page. Sign-in uses OAuth 2.0 with PKCE in the system browser (the system sign-in sheet on iPad). The app never receives or sees the user’s Google password.
  • Minimum scopes. The app requests only the two scopes listed above and accesses no other Google data.
  • Retention and deletion. The token and channel name remain on the device only until the user disconnects. On disconnect they are deleted immediately and the token is revoked with Google (see below).
  • Security issues. If you find a security problem, contact us at the address below; we will fix it and advise on any steps to take.

Revoking access and deletion

Settings › YouTube › Disconnect removes the token from the device and revokes it with Google. Users can also revoke access at any time at https://myaccount.google.com/permissions. Please disconnect before uninstalling so that the token in the Keychain is removed as well.

AI features

If the user chooses an AI option, the transcript text is sent to the AI service the user selects (Claude, ChatGPT or Gemini) by the user’s own action or API key, under that service’s privacy policy. Google user data is never sent to AI services.

Purchase requests

Only when the user presses “Send request” on the app’s registration screen, or registers with a purchase number, the following is sent to our sales ledger: the name and email address the user typed, the device number generated by the app (8 characters), the device type (Mac or Windows), the purchase number, the registration code and the dates. It is used only to confirm payment, deliver the registration code for that device and re-issue it later. It is stored in a private Google Sheet in our own Google account, is not shared or used for advertising, and is deleted on request (transaction records are kept where the law requires). We do not receive card details. This is unrelated to Google user data: YouTube tokens and channel information are never sent to the ledger.
